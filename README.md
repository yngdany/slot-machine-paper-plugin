# SlotMachine Paper Plugin

Animated, configurable slot machines for Paper 1.21.x.

## Download

- [Download the plugin ZIP](./slot-machine-1.0.0-plugin.zip)
- [Download the JAR](./slot-machine-1.0.0.jar)

## Installation

1. Run Java 21 and Paper 1.21.x.
2. Install Vault and a Vault-compatible economy provider such as EssentialsX.
3. Copy the JAR into the server's plugins folder.
4. Start the server and edit plugins/SlotMachine/config.yml.

## Commands

- /slotmachine give classic
- /slotmachine give premium
- /slotmachine stats
- /slotmachine stats top
- /slotmachine jackpot
- /slotmachine reload

The ZIP includes the JAR, default configuration, and installation notes.
